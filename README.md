# X 双语对照翻译（Chrome 扩展 · Manifest V3）

让 X (x.com) 的官方自动翻译以 **原文在上、译文在下** 的双语对照形式显示。
完全复用官方翻译结果，**不调用任何第三方翻译 API**。

## 功能特性

- 双语对照：原文保持原位（React 原生渲染），官方译文以灰色小字 + 左侧竖线紧跟其后
- 保留「翻译自 xxx」提示文案；点击提示文字可折叠 / 展开译文
- 自动处理：
  - 开启官方「自动翻译」后所有被翻译的推文
  - 手动点过「翻译帖子」的推文
  - 引用推文被单独翻译的情况
  - 时间线滚动无限加载（MutationObserver + 兜底轮询）
- 不破坏原有交互：链接、@提及、话题标签、表情图片等原样保留
- Popup 一键开关 + 快捷键 `Alt+B`，关闭时已处理的推文还原为「仅译文」
- 模糊显示：可设置只模糊「原文」或「译文」其中一侧；支持只遮挡每句关键词或整句，悬停约 0.5 秒临时显示，移开后恢复
- 遮挡风格：轻 / 中 / 强模糊、色块遮挡、虚线下划线可选
- 下划线查词：只对英文关键词加淡点状下划线；悬停约 0.5 秒后弹出本地英汉词典释义，与遮挡功能独立。非英文内容不遮挡、不查词
- 收藏推文：时间线每条推文操作栏提供「保存推文」，保存原文、已获取的官方译文及链接到本地
- 每日复习：扩展弹窗显示今日待复习数量；每天可在独立页面逐条查看、展开译文并标记已复习
- 复习页逐句对照：有译文时自动按句配对原文与译文（句数不一致时回退为完整原文 + 整块译文），译文默认隐藏可展开
- 复习页收藏管理：每条卡片可勾选「导出选中」、「导出全部」（纯文本），右上「清空收藏」二次确认后删除全部已收藏

## 安装步骤

1. 打开 Chrome，访问 `chrome://extensions/`
2. 打开右上角「开发者模式」开关
3. 点击左上角「加载已解压的扩展程序」
4. 选择本文件夹（`xtranslate`）
5. （建议）到 x.com 设置 →「无障碍、显示和语言」→ 开启「自动翻译」，效果最佳

## 使用方法

1. 刷新 x.com 页面（安装/更新扩展后需要刷新一次）
2. 默认开启双语模式。被 X 自动翻译的推文会自动变成「原文 + 灰色译文」对照显示
3. 点击扩展图标可随时开 / 关；或使用快捷键 `Alt+B`。弹窗中可开启「下划线查词」：关键词会被加上淡点状下划线，悬停约 0.5 秒弹出本地词典释义。「模糊显示」则用于遮挡原文或译文（同一时间只能遮挡一侧），两者独立
4. 关闭模式时：已处理的推文立即还原为「仅译文」，新推文不再处理
5. 快捷键可在 `chrome://extensions/shortcuts` 中修改
6. 在时间线推文操作栏点击空心星标收藏；实心星标表示已收藏，再点可取消收藏。点击扩展弹窗中的「每日复习」开始当天复习
7. 复习页默认隐藏已保存译文，可展开对照；点击「完成今日复习」后该推文当天不再出现，次日自动重新进入复习队列。通过「全部收藏」查看或删除收藏

## 工作原理

X 自动翻译后的推文结构为：灰色提示栏（含「显示原文」按钮）+ `div[data-testid="tweetText"]`（此时内容是**译文**）。本脚本：

1. 备份 `tweetText.innerHTML`（即官方译文 HTML）
2. 程序化模拟点击「显示原文」，等待 React 把内容换回**原文**（轮询比对 innerHTML，超时 3s）
3. 在 `tweetText` 之后插入兄弟节点容器：「翻译自 xxx」说明 + 备份的译文

因为不改动 `tweetText` 内部结构，React 对原文的管理不受影响，长推文「显示更多」展开也正常（展开只会在末尾追加文本，双语块保留）。

针对虚拟列表 DOM 回收：每条记录保存了原文纯文本前缀作为指纹。节点被复用成别的推文时会指纹失配，自动清除旧双语块并按新推文重新处理。

## 已知限制与说明

- **关闭再开启**：关闭模式会把正文还原为「仅译文」，但官方横幅已被 React 移除无法凭空恢复，因此这些旧推文重新开启后不会自动变回双语（刷新页面即可）；新出现的翻译推文不受影响
- **模拟点击失败**：若某天官方改版导致点击无效，对应推文会保持官方原样并跳过（控制台无报错、不影响浏览）。替代方案是在 `content.js` 的 `processPair` 超时分支中接入第三方翻译 API（如 DeepL/Google），把返回结果填入译文块——当前版本刻意未引入
- **界面语言**：按钮识别依赖 `aria-label="显示原文"`（兼容英文 `Show original`）。如使用其他界面语言，在 `content.js` 顶部的 `SHOW_ORIGINAL_LABELS` 数组中补充对应文案即可
- **关键词遮挡范围**：逐句模式下原文和译文都支持每句一个关键词；整块模式的原文来自 X 官方 DOM，为避免破坏 React，会退回整块遮挡
- 「评价此翻译」等官方反馈控件保持原样，未做隐藏

## 词典数据

查词只使用随扩展打包的英汉精简词典，不联网、不调用第三方 API：

- 英文 → 中文：ECDICT（MIT），约 2.3 万常用词
- 非英文内容不参与遮挡和查词
- 详细授权与署名见 `data/LICENSES.md`
- 数据可用 `tools/build_dictionaries.py` 从原始词库重新生成

## 自定义样式

编辑 `content.css`：

| 类名 | 作用 |
|------|------|
| `.xtl-wrap` | 双语块整体（左边框颜色在此调整） |
| `.xtl-note` | 「翻译自 xxx」说明行 |
| `.xtl-trans` | 译文正文（字号、灰度在此调整） |
